## 5. 한계 및 잔여 위험

- 실제 존재하는 등기번호의 정상 조회는 운영 키로 시험하지 못했습니다(샘플 XML로 대체). 배포 후 실제 번호 1건으로 확인이 필요합니다.
- 통합시험의 03·504·정상 응답은 브라우저에서 응답을 대체해 만든 것입니다. 03 판정 자체는 운영에서 받은 실제 응답 원문으로 단위시험했습니다.
- `[실패 건만 재조회]`가 `정보없음`을 제외하는지는 코드(`shouldRun`)로 확인했고 별도 실행시험은 하지 않았습니다.
- 이 브랜치는 아직 Vercel에 배포되지 않았습니다. 운영 반영에는 main 병합(또는 PR)이 필요합니다.
